Independent PRONI Search is an app created independently by Civgraph, which contains all 1,538,177 records which exist on the official PRONI eCatalogue, while providing an easier user interface, powerful search features, exportable spreadsheets of record data, and easily-shareable records.

Civgraph, and this app which it runs, are independent of, unassociated with, and not endorsed by the Public Record Office of Northern Ireland. This app is not an official PRONI service.

You can find the official PRONI website here, and the official PRONI eCatalogue here.
