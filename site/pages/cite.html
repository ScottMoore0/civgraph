How to cite

How to cite Civgraph, one of its records or maps, a dataset snapshot or the API, and the original sources behind them.

Always cite the original source

Civgraph brings together records made by others: election results from returning officers and electoral offices, boundaries from Ordnance Survey and statistics offices, debates from parliaments, catalogue entries from archives. Every record on Civgraph shows where it came from. Cite that original source first, in the form your discipline uses, and add Civgraph as where you found it.

Electoral Office for Northern Ireland, [title of the result sheet], [date]. Accessed via Civgraph, https://civgraph.net/browse/elections/[election], [date accessed].

Cite Civgraph on its own only for what Civgraph itself made: a compiled or checked result, a digitised boundary, a link between records, a derived count, or the dataset as a whole. Records are corrected as new sources are checked, so always give the date you looked at a page.

Use these addresses. They are the ones the site gives as each page's permanent (canonical) address.

A record page

Each election, person, party, office, map, source and register-of-interests entry has its own page with a permanent address under https://civgraph.net/browse/. Cite the address and the date you looked at it.

Plain text

Civgraph contributors (2026). 2024 Irish general election. Civgraph. https://civgraph.net/browse/elections/dail-eireann-2024-11-29 (accessed 11 November 2026).

BibTeX

@misc{civgraph-dail-2024,
  author       = {{Civgraph contributors}},
  title        = {2024 Irish general election},
  howpublished = {Civgraph},
  year         = {2026},
  url          = {https://civgraph.net/browse/elections/dail-eireann-2024-11-29},
  urldate      = {2026-11-11},
  note         = {Original sources as listed on the record}

A PRONI record

Civgraph's PRONI pages reproduce descriptions from the Public Record Office of Northern Ireland's eCatalogue. The archive and its reference come first. Add Civgraph's page if that is where you read the description.

Public Record Office of Northern Ireland, LA/1, Antrim County Council, 1796-1987 (eCatalogue description). Accessed via Civgraph, https://civgraph.net/proni/LA/1 (accessed 11 November 2026).

A map or map feature

Name the people who digitised the map, as shown on it, and the original map or source they worked from. The map catalogue's "Cite" item, in each map's menu, copies a citation in this form with the map's link.

[Contributors' surnames and initials, as the map names them] ([year]). [Map title] [digitised boundaries]. Civgraph. https://civgraph.net/browse/maps/[map] (accessed [date]).

To point at one feature, such as a single constituency, use its feature link, which opens the map on that feature:

Civgraph contributors (2026). Belfast West, Parliamentary Constituencies 2023 [map feature]. Civgraph. https://civgraph.net/maps/#layers=pc-2023&featureMap=pc-2023&featureId=BELFAST+WEST (accessed 11 November 2026).

If you reproduce a map with its background, keep the background's credit, as shown on the map. See Licence for what each source requires.

A dataset snapshot

For work that others should be able to repeat, cite the bulk download you used, by its version. Downloads are published as versioned snapshots: each records database has a version in its file name, and its SHA-256 checksum is in the downloads manifest. Cite the versioned name, not civgraph-records-latest, which moves to each new snapshot.

Plain text

Civgraph contributors (2026). Civgraph records database, version e97ec87cc8acb0f0 [dataset]. https://data.civgraph.net/data/downloads/civgraph-records-e97ec87cc8acb0f0.sqlite.gz. SHA-256 19bb27034016f1b43eb5bb13846d2a038580887d8fca02777978094be5a59214.

BibTeX (biblatex)

@dataset{civgraph-records-e97ec87cc8acb0f0,
  author  = {{Civgraph contributors}},
  title   = {Civgraph records database},
  version = {e97ec87cc8acb0f0},
  year    = {2026},
  url     = {https://data.civgraph.net/data/downloads/civgraph-records-e97ec87cc8acb0f0.sqlite.gz},
  urldate = {2026-11-11},
  note    = {SHA-256 19bb27034016f1b43eb5bb13846d2a038580887d8fca02777978094be5a59214}

The API

If you used the API, cite the request address and the date you made it. For repeatable work, cite the dataset snapshot as well, since the API always answers from the newest records.

Civgraph contributors (2026). Civgraph API v1, /api/v1/persons?slug=[person] [data set]. https://civgraph.net/api/v1/persons?slug=[person] (accessed 11 November 2026).
